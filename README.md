# SeriousHL — движение и оружие Half-Life в Serious Sam Classic

Игрок Serious Sam Classic (The First Encounter 1.05, The Second Encounter 1.07) бегает, прыгает, приседает, стрейфится
в воздухе, распрыгивается (bunny hop) и улетает от взрывов по правилам Half-Life 1; в руках — оружие Half-Life: его
модели с анимациями, вспышки, звуки, меню слотов 1–5; HUD, звуки шагов, фонарик и броня — как у костюма HEV; плавание —
по HL (и в сборке для спидрана). Модели, спрайты и звуки берутся из твоего установленного Half-Life (без него — Сэма).
Монстры, уровни, заставки — Сэма. Есть закрытая сборка для спидрана
(только движение, ниже). Таймер RTA/IGT, LiveSplit и спидометр — отдельный мод
[SeriousSpeedrun](https://github.com/animeliodas/SeriousSpeedrun) (он и для обычной игры; с SeriousHL —
`sr_iSpeedUnits 1`, скорость в юнитах HL). Плагин [Serious Sam Classics Patch](https://github.com/SamClassicPatch/SuperProject) 1.9.4; порт
[SeriousBridge](https://github.com/animeliodas/SeriousBridge) — ядра для механик других игр в Serious Sam.

> Сделано с помощью Claude Code (ИИ). Проверено скриптом в настоящих играх (TFE и TSE, `tools/test_hl.py`, ниже).
> Только одиночная игра. Не связано с Valve и Croteam.

## Установка (один клик)

1. Скачай `SeriousHL-<версия>.zip` (или `SeriousHL-<версия>-run.zip` — сборку для спидрана) со страницы
   [Releases](https://github.com/animeliodas/SeriousHL/releases), распакуй куда угодно.
2. Запусти `Install.cmd`. Он сам найдёт TFE и TSE в Steam (или GOG; или перетащи папку игры на `Install.cmd`),
   поставит Classics Patch 1.9.4, если его нет (скачает с его страницы релизов на GitHub, проверит SHA-256), положит
   `SeriousHL.dll` в `Bin\Plugins` и ярлык на рабочий стол. Если найдёт Half-Life (Steam; или `-HalfLife "<папка
   Half-Life>"`), спросит и скопирует звуки оружия HL из твоей игры в `<игра>\Sounds\SeriousHL` (они остаются на твоём
   ПК, в архиве их нет; без них — звуки Сэма). Только звуки: `install.ps1 -AssetsOnly`.
3. Играй с ярлыка (или `Bin\SeriousSam_Custom.exe`; в Steam — параметр запуска `+game ClassicsPatchMod`).

Удаление: `Uninstall.cmd` (Classics Patch остаётся). Без интернета: положи zip Classics Patch
(`TFE1.05_2025_10_15.zip` / `TSE1.07_2025_10_15.zip`) рядом с `Install.cmd`. Вручную: `TFE\SeriousHL.dll` или
`TSE\SeriousHL.dll` из архива — в `<игра>\Bin\Plugins\`.

## Что как в Half-Life

| | Half-Life (`pm_shared.c`) | здесь |
|---|---|---|
| бег | `sv_maxspeed` 320, `sv_accelerate` 10, `sv_friction` 4, `sv_stopspeed` 100 | так же: 320 u/s, остановка с бега за ~0.53 с |
| воздух | `sv_airaccelerate` 10, прибавка вдоль желаемого — до 30 u/s | так же: стрейф мышью + A/D набирает скорость |
| прыжок | 45 юнитов, √(2·800·45) = 268 u/s, до трения | так же: прыжок в тик приземления не теряет скорость — банихоп |
| кап банихопа | в Steam HL: больше 1.7×320 — прыжок режет до 65 % | `hl_bBhopCap 0` (как Bunnymod XT `bxt_bhopcap 0`), `1` — как Steam |
| край | `edgefriction` 2 у обрыва | так же (лучи вниз перед ногами) |
| гравитация | `sv_gravity` 800 | 800, умноженная на гравитацию уровня Сэма к обычной (30 м/с²) |
| урон от падения | с 580 u/s, смерть с 1024 | так же; удары о стены по-сэмовски не ранят |
| присед | ×0.333 к скорости после 0.4 с на земле; в воздухе сразу, ноги поднимаются на 18 юнитов | так же: прыжок с приседом — 63 юнита (1.87 м) |
| ducktap | отпустил присед на земле раньше 0.4 с — стоячий хитбокс подскакивает на 18 юнитов | так же: отрыв от земли без прыжка |
| прыжок в приседе | прыжок и присед держатся вместе: прыжок пригнувшись, банихоп в приседе | так же (у Сэма они складываются в одно число вверх-вниз, и вместе он просто вставал — теперь это прыжок пригнувшись) |
| отброс от урона | скорость += от источника × урон·5 u/s (в приседе ·10), не больше 1000 | так же: рокет-джамп и бусты гранатами по HL (толчок Сэма убран) |
| кадры | движение считается на каждом кадре (обычно 100 fps) | `hl_iFps 100`: 5 шагов HL в каждом тике Сэма (20 Гц), поворот мыши размазан по ним |
| вода: уровни | `PM_CheckWater`: ноги, середина корпуса, глаза (28 над серединой) | так же — по коробке коллизии Сэма; в воде он держит стоячую коробку (2.25 м, как корпус HL) и камеру на 1.9 м, а не плавательную |
| вода: плавание | по пояс и глубже: без гравитации, плывёшь, куда смотришь, 0.8 скорости (256 u/s), трение воды; без клавиш тонешь (48 u/s) | так же; плавучесть и «плавание» движка Сэма вычтены точно |
| вода: прыжок | держишь прыжок — вверх 100 u/s (~96 с трением): держит у поверхности | так же |
| выпрыгивание | по пояс у вертикальной стенки, над которой есть место: вверх 225 u/s, толчок к стенке 50 u/s, до 2 с (пока не вышел из воды) | так же |
| падение в воду | урона нет, если ноги в воде | так же |

Юнит: глаза Сэма (1.9 м) там же, где у игрока HL (64 юнита) — 1 u = 2.97 см (`hl_fUnit`): бег 9.5 м/с (у Сэма
10), прыжок 1.34 м (у Сэма около 2 м — высокие уступы Сэма бывают не допрыгнуть; `hl_fJumpHeight`).

когда она в руках, меняет одну на другую. Трипмина — модель `v_tripmine.mdl` HL на стене и её лазер (`laserbeam`)
поверх мира Сэма, в его глубине; внутри — граната Сэма (её взрыв и урон), неподвижная и невидимая; от взрыва рядом
трипмины рвутся цепочкой. Перезарядка — клавиша перезарядки Сэма (по умолчанию левый
Alt), и сама, когда магазин пуст. Правая кнопка, пока в руках ствол HL, — второй огонь, а не Netricsa (Netricsa —
Enter). Подобранные патроны Сэма — запас для магазинов.

### Что видно и слышно (из твоего Half-Life)

- **Модели в руках** — `v_*.mdl` HL с их анимациями (достать, ждать, выстрел, перезарядка, убрать; раскрутка гаусса,
  луч эгона, пульт сэтчела), покачивание при беге (`V_CalcBob`), вспышки у дула и звуки перезарядки из событий модели.
- **HUD HL** — здоровье, заряд костюма, патроны «магазин | запас», вторые патроны (гранаты MP5), прицел ствола, фонарик;
  набор спрайтов по экрану, как в HL25 (640 / 1280 / 2560); история подбора справа внизу (патроны с количеством,
  ствол, аптечка, батарея — 5 с, гаснет за последние 3). HUD и прицел Сэма на это время выключены.
- **Меню оружия** — слоты 1–5 как в HL (повторное нажатие листает слот, огонь берёт; колесо — по всем; клавиша
  «сменить оружие» Сэма — последнее, как `lastinv`); клавиши 6–9 остаются Сэма.
- **Звуки игрока** — шаги по поверхности (песок/трава/снег — земля, вода — хлюпанье, по пояс — брод) в темпе HL,
  прыжок, приземление, боль от падения, плавание, боль; свои звуки Сэма (шаги, «ух» прыжка, боль) тем временем молчат.
- **Фонарик** — F, заряд (1 % за 1.2 с горения, заряжается 1 % за 0.2 с), пятно света там, куда смотришь.

### Костюм HEV

Броня по HL (`CBasePlayer::TakeDamage`): 80 % урона на броню, очко брони держит два очка урона, кончилась — остальное в
здоровье; от падения и утопления не спасает. У Сэма — ⅔ на броню, очко за очко. Сложность Сэма умножает урон до
брони, как у него; урон от падения — по HL на любой сложности. `hl_bHevArmor 0` — броня Сэма.

Голос костюма (`CBasePlayer::TakeDamage`, `SetSuitUpdate`): фразы из `sound/sentences.txt` твоего HL, слово за словом
из `fvox`, как это делает VOX движка (высота, громкость, обрезка слова, паузы на запятых). Переломы, порезы, потеря
крови, химия — по виду и силе удара; при первом сильном — «automedic on» и «morphine shot»; здоровье критическое,
при смерти, «seek medical attention»; уровень заряда при подборе брони («power level is …»). Одна фраза за раз, следующая —
через 3.5 с, каждая не чаще своего срока. Громкость — как `suitvolume` HL (0.25).

## Сборка для спидрана (RUN)

`SeriousHL-<версия>-run.zip`: только движение (оружие и баланс — оригинальные сэмовские); правила HL зашиты намертво
(таймер, LiveSplit, спидометр — [SeriousSpeedrun](https://github.com/animeliodas/SeriousSpeedrun)) — автопрыжок, без капа банихопа, 100 fps,
скорости, трение, гравитация, присед, отброс и плавание как в Half-Life. Переменных `hl_*` в консоли нет (менять нечего:
`hl_bAutoJump=0` → «Identifier is not declared»), тестовых хуков нет. В левом нижнем углу экрана — метка
`SeriousHL <версия> RUN <8 цифр>`: начало SHA-256 самой DLL (полный хэш — в `SeriousSam_Custom.log`). Модераторы
сверяют её на видео забега со списком в описании релиза. Ставится тем же `Install.cmd` (заменяет обычную сборку,
обычный архив возвращает её).

## Как это сделано

Ядро SeriousBridge (`core/sam/Movement`) через функцию-патч Classics Patch цепляется на
`CMovableEntity::PreMoving` движка: каждый тик, когда Player.es уже применил действие игрока, а движок ещё не сдвинул
его, ускорение и торможение Сэма обнуляются, его собственный прыжок убирается, «ходьба» не останавливает у края;
правила порта получают, что сделал мир (стены, пол, взрывы, движущийся пол), и отдают скорость; гравитация уровня,
которую движок всё равно добавит, вычитается заранее. Клавиши берутся из самого применённого действия
(`CPlayer::ApplyAction`) — ровно того тика. Правила HL — одна «чистая» функция (`Rules.cpp`: вход тика → выход),
игровая сторона (`HlMove.cpp`) заполняет вход и применяет выход; отброс от урона — патч `CPlayer::DamageImpact`.

Оружие (`Weapons.cpp`): фильтр действий ядра убирает из каждого действия огонь и перезарядку Сэма, пока в руках ствол
HL; дальше каждый тик — правила HL, а выстрел — экспортированными функциями оружия Сэма (`FireMachineBullet`,
`FireBullets`, `CutWithKnife`, `FireRocket`, `FireGrenade`, `SetFlare`, `DoRecoil`) с уроном и разбросом HL, анимация —
по имени из модели (`FIRE1`, `ATTACK01`…), звук HL — из `Sounds\SeriousHL` (данные звука держит плагин, а 3D-параметры
звукового объекта ставит сам перед каждым звуком: Сэм оставляет их заглушёнными), иначе — компонентом класса оружия
(`(402 << 8) | номер`). Броня — патч `CPlayer::ReceiveDamage` (`Hev.cpp`). Именно движение Сэма портило прошлые попытки: на земле он каждый
тик тянет скорость к желаемой (100 м/с², торможение 60), а прыгает только после 0.25 с без вертикального движения —
это и убивало банихоп.

## Сборка и проверка

VS 2022 Build Tools (v143, x86). Рядом должны лежать ядро и SDK Classics Patch:
```
<папка>/serioushl            этот репозиторий
<папка>/seriousbridge        git clone https://github.com/animeliodas/SeriousBridge seriousbridge
<папка>/_deps/SuperProject   git clone --branch 1.9.4 --recurse-submodules https://github.com/SamClassicPatch/SuperProject.git
```
`plugin/build.sh` (Git Bash) → `plugin/dist/Release_TFE105|Release_TSE107/SeriousHL.dll`; `plugin/build.sh all run` —
сборка для спидрана в `plugin/dist/Run_*`; `python tools/make_release.py [run]` → `release/SeriousHL-<версия>[-run].zip`.

Оракул в настоящей игре (`SERIOUSBRIDGE_DEV=1`; `--launch` запускает игру сам, копируя `SaveGame` в сторону):
```
python tools/test_hl.py --game "<папка игры>" --launch
```

закрывает игру. Грабля: `StartMap` из меню берёт режим заставки (flyover) — TFE 11_AlleyOfSphinxes в нём виснет;
тест ставит `gam_iStartMode=0`, `gam_iStartDifficulty=1`.
